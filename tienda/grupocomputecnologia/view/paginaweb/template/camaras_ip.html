CÁMARAS IP ANTI-VANDÁLICAS


Dispone de un sensor de imagen 1/3'' CMOS Color ofreciendo una resolución máxima de 1.3 Megapíxel (1280x960) con formato de compresión de imagen H.264.

Una óptica fija de 3.6 mm permite captar un campo de visión diagonal de 92 grados y gracias a sus 24 LEDs infrarrojos que se activan automáticamente proporcionando así una imagen nítida a 0.0 Lux (oscuridad total) podrá visualizar y grabar objetivos a una distancia máxima de 20 metros. También dispone de filtro IR CUT automático que permite obtener colores nítidos y reales durante el día.
Resistente al agua, según protocolo IP66, puede ser usada tanto para interior como para exterior.
